# Ferro Studio — sitio web

Proyecto independiente (Vite + React), listo para desplegar en Vercel.

## Subir a Vercel
1. Subí esta carpeta a un repositorio de GitHub (o arrastrala directo en vercel.com -> "Add New Project" -> "Deploy" si usás la opción de subir carpeta).
2. En Vercel, al importar el proyecto, dejá la configuración automática (detecta Vite):
   - Build Command: npm run build
   - Output Directory: dist
3. Deploy. Listo.

## Desarrollo local
npm install
npm run dev
